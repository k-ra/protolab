# Protolab

A running log of experiments in simulating pressings, indentations, print processes, and finishes on digital paper. Favorite techniques are kept as reusable materials and carried into new work.

[The sheet](https://k-ra.github.io/protolab/protolab/) holds the experiments together: plant and edit specimens, move them around the paper, change the light, and save the ones worth keeping. [Clippings](https://k-ra.github.io/protolab/canvas/) puts materials and printing methods beside one another for comparison. Individual studies include [The Press](https://k-ra.github.io/protolab/press/), [Specimen](https://k-ra.github.io/protolab/flowers/), and [Sigil Pressure](https://k-ra.github.io/protolab/wax-seal/).

Everything is drawn as a height field and lit in the browser. There is no build step; serve the folder with `npx serve .` to run it locally.
